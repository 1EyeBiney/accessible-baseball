
### v1.3.0 — The Acoustic Depth Update
- **Dynamic Panning Sweep:** Pitches no longer spawn already panned to their zone. The audio now originates at center `0.0` (the pitcher's hand) and dynamically sweeps to the target pan (`-0.9` or `0.9`) over the flight duration, creating a pronounced 3D trajectory.
- **Wider Stereo Field:** Increased the extreme panning limits in `base_state.js` from `0.7` to `0.9` to make inside and outside pitches much easier to distinguish.
- **Acoustic Stutter (LFO):** Re-introduced the "radar blip" effect from the original prototype using Web Audio LFOs. High pitches (Zones 7,8,9) remain smooth fastballs. Mid pitches (Zones 4,5,6) feature a rapid 15Hz flutter. Low pitches (Zones 1,2,3) feature a heavy 8Hz "chug."
- **Velocity Mapping:** Mapped random pitch speed generation to the height of the zone to match the acoustic profiles. High zones are 90-100mph, Mid zones are 80-89mph, and Low zones are 70-79mph.### v1.2.0 — Calibration & Telemetry
- **Pitcher Command Lock:** Temporarily set default `commandRating` to 100% to ensure 1-to-1 accuracy between the pre-pitch hum target and the actual pitch location for baseline calibration.
- **Manhattan Distance Collision:** Replaced the binary zone check with a grid-based Manhattan distance calculation. Distance 0 is a clean hit, Distance 1 is a Foul/Topped ball, and Distance 2+ is a Swing and Miss.
- **Raw Audio Telemetry:** Re-wrote ARIA announcements to explicitly speak the raw timing offset in milliseconds (e.g., "45ms late" or "20ms early") on all fouls and misses to aid in swing correction.
- **Restored Polish Pass:** Implemented the `playCatcherMitt()` closure audio and added the `WIND_UP` / `BATTER_UP` state guard to the swing style cycler.
### v1.1.4 — Engine Polish & Boot State Fix
- **Boot Sequence State:** Fixed a critical bug in `base_core.js` where `_handleBoot()` incorrectly set the engine state to `DERBY_SETUP` instead of `BATTER_UP`. This successfully unblocks the Spacebar listener in `base_input.js`, allowing pitches to be called properly.
- **Version Housekeeping:** Updated the `<title>` tag in `index.html` to consistently reflect the v1.1.4 engine version.
### v1.1.3 — Derby Game Loop & Initialization Hotfixes
- **State Initialization:** Fixed the "silent abort" bug by explicitly forcing the engine into the `BATTER_UP` state during `initSystem()`, successfully unlocking the Spacebar listener.
- **Derby Pitch Generation:** Updated the Spacebar input trigger to automatically generate a random target zone (1-9) to feed the pitch engine during Home Run Derby mode.
- **Windup Sequence:** Overhauled `launchPitch()` to properly handle the `WIND_UP` state transition, calculate pre-flight telemetry, and orchestrate the delay before audio generation.
- **Game Loop Integration:** Implemented the full Derby session logic, including tracking `pitchesRemaining`, scorekeeping for homers, and a 3-second auto-advance timer to reset the batter after a result announcement.
### v1.1.2 — Swing Styles & The Fat Pitch
- **Physics Calibration:** Integrated `swingStyle` modifiers. Choke Up adds a 15ms buffer to the timing window; Power Swing reduces it by 10ms but increases "Distance" telemetry.
- **Fat Pitch Mechanic:** Finalized the "Command Miss" logic. If the pitcher misses their target, the ball is routed to Zone 5. Any swing in the middle row (4, 5, 6) now results in a "Flush" hit on a command miss.
- **Audio Feedback:** Standardized `playPlateSync` volume to 0.5 to ensure it is audible over 100mph fastball Doppler effects.
- **Telemetry Buffering:** Added a `BASE.state.lastShot` object to store the precise timing offset and zone differential for post-pitch review.
### v1.1.1 — Hitting Logic Refinement
- **Input Guarding:** Fixed a bug where multiple swing audio cues could trigger during a single pitch; the first keypress now "locks" the swing.
- **Timing Calibration:** Adjusted the hitting window to be style-aware: Choke Up now provides a +/- 10ms wider window than Power swings.
- **System Key Pass-through:** Verified and reinforced that browser-level keys (F5, F11, etc.) bypass the game's `preventDefault()`.
- **Telemetry Update:** Added "Speed" and "Zone" output to the `#visual-buffer` for post-pitch debugging.
\### v1.1.0 — The 9-Zone Hitbox \& Swing Styles

\- \*\*Numpad Mapping:\*\* Implemented a 3x3 hitting grid using Numpad 1-9. Pressing a zone key now acts as the direct swing trigger.

\- \*\*Swing Style State:\*\* Added `standard`, `choke\_up`, and `power` styles, toggled via Numpad Plus and Minus.

\- \*\*Plate Crossing Cue:\*\* Introduced a high-frequency "sync pulse" when the ball reaches the hitting zone, occurring shortly before the catcher's mitt sound to assist with timing.

\- \*\*Contact Logic:\*\* Integrated basic "Thwack" audio feedback for successful timing (Standard Sine at 440Hz).

\- \*\*Keyboard Control:\*\* Reinforced strict focus management and `e.repeat` filtering, while preserving system keys (F5, F6, Ctrl+PgUp/Dn, Esc).
